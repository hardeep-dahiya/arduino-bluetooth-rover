# Arduino-Based Bluetooth Mobility Rover

## Overview
This project is a Bluetooth controlled smart rover developed using Arduino UNO. The rover can move wirelessly and detect obstacles using ultrasonic sensors.

## Features
- Bluetooth Control
- Obstacle Detection
- Servo Motor Scanning
- Wireless Movement

## Components Used
- Arduino UNO
- HC-05 Bluetooth Module
- HC-SR04 Ultrasonic Sensor
- L298N Motor Driver
- Servo Motor
- DC Motors

## Technologies Used
- Arduino IDE
- Embedded C

## Future Improvements
- STM32 Integration
- IoT Monitoring
- Camera Module
